# Bluefit × PM-SP + Shape

Site estático pronto para publicar na Vercel.

## Como abrir
Abra `index.html` no navegador. Os registros ficam salvos no armazenamento local do navegador.

## Como publicar na Vercel
1. Extraia o ZIP.
2. Acesse https://vercel.com/new e entre na sua conta.
3. Escolha **Add New Project** e importe um repositório GitHub com estes arquivos, ou use a opção de deploy pela CLI.
4. Não é necessário configurar framework, build command ou output directory; é um site estático com `index.html` na raiz.

## Observações
- A galeria usa duas imagens da reportagem do Marília Notícia sobre a unidade Bluefit Marília (2022). Elas podem deixar de carregar caso o site de origem altere os endereços.
- A reportagem confirma áreas e estrutura, mas não fornece um inventário atualizado dos aparelhos.
- O app não tem login nem sincronização em nuvem. O histórico fica no navegador/dispositivo usado; use Exportar para guardar uma cópia.
- O plano de treino é uma versão inicial editável, a confirmar com os aparelhos realmente disponíveis e com orientação profissional.
